# 強化秘話の準備試験（2026-10-23）

実機の強化秘話との互換性は、まだ確認していません。[試験手順](ENHANCED_TEST.md)に沿って照合します。

## ランダムなマスクとオフセットの回収

LibriSpeechの評価用発話をThumbDVで符号化したデータから、自然音声1.2秒を使用しました。
seed `981027` で最大周期のマスク、オフセット、表示鍵、発話を選び、生成側でXORしました。
探索に渡したのは暗号化した`.burst`と既知の表示鍵です。正解ファイルは終了後の採点だけに使いました。

| 項目 | 結果 |
|---|---|
| 仕込んだ15-bitマスク | `0x481B`（先頭ビット付き多項式表記 `0xC81B`） |
| オフセット / 表示鍵 | `5495` / `12197` |
| 初期状態 | `17692` |
| 探索範囲 | 全32,768マスク × 全32,767非ゼロ初期状態 |
| 列挙した組み合わせ | 1,073,709,056 |
| 結果 | マスク・オフセットともに一致、順位1位 |
| 計算時間の累計 | 1,062.69秒（17分42.69秒） |
| 足切り後に残った候補 | 100,045,879（9.32%） |
| 1位 / 2位の最小スコア | 18.008 / 11.002 |

FFNNの閾値は−10で、3区間のいずれかが通ればhybridへ渡しています。
全256区画のうち最初の63区画は残った全候補を全3区間で判定し、残り193区画は
最小スコアによる順位の上界を使って追加区間を省略しました。途中でチェックポイントから再開しています。
時間は完了区画の計算時間の合計で、停止中の時間と起動処理は含みません。
これは1発話・1組のランダムなパラメータでの回収成功であり、すべての音声条件での成功を示すものではありません。
復元したマスクとオフセットを通常の`descramble`へ渡し、出力した60フレームが元のチップ出力とビット単位で一致することも確認しました。

## GPUベンチと最悪ケースの見積もり

RTX 4070 Ti SUPER（16 GB）、PyTorch 2.11.0 + CUDA 12.8、FP32、TF32無効で測定しました。
バッチサイズ128〜8192を比較し、最速だった1024を採用しています。
GPU上の系列生成、XOR、モデル推論、上位候補の回収を含め、各条件をウォームアップ後30秒測りました。

| 条件 | 候補/秒 | 2^30候補への外挿 | 平均GPU使用率 |
|---|---:|---:|---:|
| hybridのみ・1区間 | 181,061 | 1.65時間 | 97.8% |
| hybridのみ・3区間 | 59,840 | 4.98時間 | 98.7% |
| 足切りを全候補が通過・3区間 | 60,769 | 4.91時間 | 98.5% |
| 閾値−10＋順位上界・3区間、今回の入力 | 1,368,016 | 13.08分 | 86.1% |

**最悪ケースの計画値は、3区間すべてを精密判定して約5時間**です。
全候補通過の測定は閾値を−1,000,000に下げ、候補が一つも落ちないことを検査しました。
4.91時間と4.98時間の差は短時間測定の変動で、足切りが効かなくても高速化するという意味ではありません。
13.08分は今回の入力に対する外挿で、最悪ケースの上限ではありません。
録音・FEC・起動・チェックポイントI/Oは含みません。約5時間という値も実測速度からの推定です。
GPU上での確認2件を含む33件のテストはすべて通過しました。

測定ログは`build/enhanced-gpu-sweep-benchmark.json`、バッチサイズ比較は
`build/enhanced-hybrid-benchmark-01.json`に保存しています。

## その他の確認

- 候補17系列×3鍵×日本語・英語各1発話の計102条件で、正しい系列がすべて1位でした。
- 17系列×全鍵の別試験でも正解が1位でした。標準秘話の既存無線機録音でも標準系列が1位でした。
- FFNN足切りは自然音声の335発話を対象に測定しました。調整用729組・評価用726組の
  重複しない1.2秒窓では、正解候補の取りこぼしは0でした。RF誤りは加えていません。
- 閾値は調整用データだけで決め、評価用には同じ値を適用しました。3区間中の最大スコアの最悪値は
  調整用10.194、評価用13.224でした。将来の入力でも同じ余裕があるとは限りません。

詳細ログと音声データはGit対象外の`build/`に置いています。
`enhanced-random-01/check.json`、`enhanced-validation-01/validation.json`、
`enhanced-prefilter-calibration.json`から再確認できます。
